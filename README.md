# homebrew-tabsmith

Homebrew formula for [tabsmith](https://github.com/PedroLaRosa/tabsmith) on macOS and Linux.

```sh
brew install pedrolarosa/tabsmith/tabsmith
tabsmith setup
```

The formula installs the binaries from tabsmith's GitHub release, pinned to the checksums in its `SHA256SUMS`.
Upgrade with `brew upgrade tabsmith`.
